# Homebrew Tap

Homebrew tap for applications by [walcew](https://github.com/walcew).

## Installation

```bash
brew tap walcew/tap
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `chatmine` | Extract chat history from desktop apps (Teams, WhatsApp) for AI agents |

### Install a formula

```bash
brew install walcew/tap/chatmine
```

## Available Casks

| Cask | Description |
|------|-------------|
| `openfortivpn-connect` | macOS GUI client for openfortivpn VPN connections |

### Install a cask

```bash
brew install --cask walcew/tap/openfortivpn-connect
```
